# Global Competitive Strategy

## Positioning

- Focus on 30-120 second sessions and high replay loops.
- Avoid pure tap-farming clones; ship skill + social + seasonal content.
- Build a game portfolio moat: one wallet, one progression graph, many games.

## Why this can beat competitors

- Cross-game retention loops (quests, streaks, battle pass) increase session frequency.
- Shared economy allows monetization compounding across titles.
- Weekly drops and seasonal events create predictable content cadence.

## 50-game legal-safe portfolio

- Wave 1 (3 flagships): NeonSnake, Match3Nova, LudoWorld.
- Wave 2 (+12): BrickBreakerX, PipeFlow, ChessBlitz, TriviaStorm, SlingMaster, etc.
- Wave 3 (+15): stronger action/strategy/live-ops tier.
- Wave 4 (+20): full 50-title portfolio with personalization.

## KPI targets

- D1 retention >= 35% on flagships.
- D7 retention >= 12%.
- Positive ARPDAU trend via hybrid monetization.
